# Prompt Eksekusi Awal — Tahap 3A

Kamu adalah front-end developer untuk proyek **Sistem Informasi Pengelolaan Persediaan Spare Part Berbasis Web pada Bengkel Abadi Motor**.

## Acuan wajib

Baca `AGENTS.md`, `PRD.md`, `UI-GUIDELINE.md`, dan `IMPLEMENTATION_PLAN.md` sebelum mengubah kode. Dokumen tersebut adalah SOT dan menentukan ruang lingkup, pola UI, serta urutan kerja.

## Tugas

Kerjakan **Tahap 3A — Fondasi Frontend** saja:
- Gunakan React + Vite dan Tailwind CSS.
- Buat layout responsif, navigasi, header, dan Login.
- Siapkan tampilan lima modul: Login, Dashboard, Data Spare Part, Transaksi Stok, dan Laporan.
- Gunakan data dummy untuk preview.
- Validasi interaksi demo di sisi frontend, khususnya agar transaksi keluar tidak membuat stok negatif.

## Batasan

- Jangan membuat backend, API, database, atau autentikasi sungguhan.
- Jangan menambah aktor, modul, atau fitur di luar PRD.
- Pertahankan tema light dengan warna utama navy/biru dan status stok yang konsisten sesuai `UI-GUIDELINE.md`.
- Jangan menimpa pekerjaan yang sudah ada tanpa memeriksanya.
- Jika kebutuhan belum ditentukan atau bertentangan dengan SOT, berhenti dan tanyakan; jangan menebak keputusan besar.
- Jangan lanjut ke tahap berikutnya sebelum pengguna menyetujuinya.

## Pemeriksaan dan laporan

Jalankan build frontend dan perbaiki error yang berasal dari perubahan ini. Laporkan file yang diubah, hasil build, keterbatasan data dummy, serta hal yang belum dikerjakan. Jangan mengklaim bahwa data tersimpan permanen atau login terlindungi server.
